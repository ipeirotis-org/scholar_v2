Help

What is PiP-AUC?

PiP-AUC (Paper-in-Percentile Area Under Curve) combines citation quality with publication productivity into a single 0-to-1 score. Each paper is ranked against all papers published in the same year, and an author's publication count is compared to faculty at similar career stages.

How are percentiles calculated?

All metrics (h-index, citations, i10-index, publication count) are percentile-ranked {% if data_source == "gs" %} against active authors among the Google Scholar profiles we track {% else %} against active authors in the Semantic Scholar dataset {% endif %} who started publishing in the same year. This age-aware normalization prevents bias toward senior researchers.

How often is data updated?

{% if data_source == "gs" %} Author and publication data comes from public Google Scholar profiles. Profiles are refreshed on a rolling schedule, and a profile we have not seen before is fetched the first time it is requested. Citation-over-time charts are not available yet. {% else %} Author and publication data is sourced from the Semantic Scholar Academic Graph Dataset, which is updated weekly. Distribution tables (population percentiles) are refreshed quarterly. {% endif %}
